# 目的
本件の目的は、以下の通り。
ローカルPCの音楽フォルダのファイルのすべてをDB管理する、
DBとAsp.net（Webサービス）、サーバー構築・運用の学習、
Github Copilotとの協業、今後Github Copilotを使用してララに自動化できるかの検討と学習、
（できれば、別の統合AI（Cloud Code）に移行できるようにも意識したい）

# システム概要
PC内のフォルダに音楽ファイルが多量に保存されており、
この中から任意の条件＋ランダム要素を加えて、いくつか選定し、別フォルダ（ホストＰＣ内）に出力する。また、この時のプレイリストは保存しておく。

プレイリスト作成について、
次にプレイリスト作成するとき、前に選択したもの以外で今回作成、といったこともしたい。
また、曲にいくつかタグ（#1990年代、#夏、#ヒット曲など）をつけておいて、これも条件の1つとしたい。

音楽があるフォルダは、ホストPCの拡張HDD内にある。

# 構成
