# 本プロジェクトの概要
Github Copilot (VsCode)環境で、ユーザー使用したチャット履歴（質問）をすべて取得して、ファイルに記録するプログラムを作成する。
（できれば回答も収集できれば良い）

# 背景
ユーザーはGithub Copilotを業務（ソフトウェア開発）で使用しているが、Copilotの本格使用の期間は２カ月ほどとまだ短い。
（AIの使用について、まだ流行し始めたばかりなので、ナレッジが少ない。）

今後の目標として、Copilotと協力して、業務を効率化したいと考えていて、
最終的に、AIをオーケストレーションで構成し、これを使用してユーザーは最終決断だけをするようになれば、良いと思っている。

段階的に対応したいので、一旦AIには作業をしてもらって、ユーザーはそのレビューをできればよいと思っている。また、そのレビューもAIにアシストを受けながら行おうと思っている。

現状として、２，３個のカスタムエージェントを作成したり、いくつかの作業をprompt.md化したり、２，３個のCopilot Skillを作成したりしており、まだまだ発展途上である。

作業としては、要件定義~テストまで一連のドキュメント作成とコーディング、そして作業（プロジェクト）全体の計画や進捗管理をする想定。

まず、上記の事を達成するために、手動でCopilotを使いながら作業を行い、その中で有益なプロンプトを吟味して、少しずつ作業エージェント・スキルなどを作成していこうと思っている。

現状では、実体験を頼りに手作業でエージェントやスキルを作成しているが、手入力の質問内容を機械的に収集・分析して、さらなる拡充をしたい。

# 目的
ローカル環境（VsCode＋Copilot）でユーザーが入力したCopilotのプロンプトをすべて収集するプログラムを作成する。

どのような処理などが必要かわからないため、今回はサンプルプログラムを作成する。

## サンプルプログラムで調査したいこと
- 質問内容は、質問のタイトル、質問の本文、質問のタグ、質問の作成日時、質問の回答数などを収集する。
- 特定フォルダを指定して、フォルダ内の全ての質問内容を収集することは可能か？
- Usersフォルダ内にvsCodeの各ワークスペース共通の設定が格納されているらしいが、必要であればこの内容も読み取る。

# コーディングルール
- コメントは適時丁寧に記載する。
- コードの実装は、ある程度の粒度でクラスや関数をする。（基本的に数10行程度で1つのクラスや関数にする）
- １つの処理について、呼び出しやネストを深くしない。
- １つの処理で多くの呼び出しやネストが深くなる場合は、実行メソッドを用意して、処理全容がわかるように実装する。（ただし、１関数で長くなりすぎないことを優先する）
- 変数のエラーチェックなどは、実行前に別メソッドで行うこと。

# 第1段階のオーケストレーション

ユーザー
  ↓
Investigation Agent
  技術調査・影響範囲・不明点を整理
  ↓
ユーザー承認
  ↓
Planning Agent
  実装計画を作成
  ↓
ユーザー承認
  ↓
Implementation Agent
  承認された範囲だけ実装
  ↓
Review Agent
  計画との差異、バグ、テスト不足を確認
  ↓
ユーザー最終判断

まず、ユーザーが手動で運用する。
調査Agentを選ぶ　→出力を確認する　→Plan Agentを選ぶ　→実装Agentを選ぶ　→Review Agentを選ぶ
