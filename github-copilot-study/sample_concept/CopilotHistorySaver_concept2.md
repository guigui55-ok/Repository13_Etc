# CopilotHistorySaver 構想書（整理版）

この文書は、サンプルプログラムの実装前に、構想内容を整理し直したものです。  
実装方針には踏み込まず、現時点での目的・前提・要望・未解決事項を明確にすることを目的とします。

---

# 1. プロジェクトの概要

GitHub Copilot（VS Code 環境）でユーザーが入力したチャット履歴を収集し、ローカル環境に記録する仕組みを検討するプロジェクトです。  
本プロジェクトの最初の目的は、Copilot の利用履歴を取得できるかどうかを確認し、必要に応じてサンプルプログラムを作成することです。

---

# 2. 確定事項

## 目的と方針
- 本プロジェクトの目的は、VS Code + GitHub Copilot で入力されたチャット内容を収集することにある。
- まずは実装ではなく、実現可能性の調査を行い、その結果をもとにサンプルプログラムを作る方針である。

## 収集の対象
- 収集対象として、質問内容のタイトル・本文・タグ・作成日時・回答数などを想定する。
- 収集の対象は、ローカル環境上の Copilot 利用履歴とする。

## 環境
- 開発環境・実行環境・調査対象環境として、Windows 11 上での利用を想定する。
- 実装言語・環境として、C# と Console アプリを前提とする。

---

# 3. 仮説

以下は、現時点での仮説であり、今後の調査で確認対象です。

- Copilot Chat の履歴は、VS Code または Copilot のローカル設定領域に保存されている可能性がある。
- 保存先として、.vscode 配下や workspaceStorage 配下が候補である。
- VS Code の各ワークスペース設定やユーザー設定が、Users フォルダ配下に保存されている可能性がある。
- 履歴の保存形式は、テキスト・JSON・SQLite・ログファイルなどのいずれかである可能性がある。
- 取得対象を特定フォルダ単位で絞ることができる可能性がある。
- もし保存形式が確認できれば、質問内容やメタ情報を抽出できる可能性がある。

---

# 4. 調査が必要な事項

以下は、今後の調査で明らかにする事項です。

- Copilot Chat の履歴が実際にどこに保存されるか。
- 履歴データの保存形式は何か。
- ワークスペースと履歴データの対応関係はどうなっているか。
- 質問タイトル・本文・作成日時・タグ・回答数などの情報を取得できるか。
- 公式な API やエクスポート機能が存在するか。
- VS Code や Copilot の更新によって形式が変わるか。
- 読み取りが利用規約・機密管理・社内規則に抵触しないか。

---

# 5. 要求

現時点で明確にした要求は、次のとおりです。

- ローカル環境でユーザーが入力した Copilot のプロンプトを収集したい。
- 収集した内容をファイルに記録したい。
- 可能であれば、回答内容も収集したい。
- サンプルプログラムを作成し、質問内容に関する情報を取得できるかを確認したい。
- 特定フォルダ内の質問内容をまとめて収集できるかを確認したい。

> なお、回答の収集は、現時点では「将来的な要望」として扱い、必須条件ではないものとして整理する。

---

# 6. 技術制約

- 対象環境は Windows 11 を前提とする。
- 実装は C# / .NET Framework / Console アプリで行う。
- 公式な取得 API が存在しない可能性があるため、保存先ファイルの読み取りが必要となる可能性がある。
- 調査対象の環境と開発環境は同じ前提とする。
- 読み取り処理は、利用規約や機密管理の観点から慎重に扱う必要がある。
