# 本アプリの目的
ローカル環境内の複数の動画・画像ファイルをスライドショー形式で1つのWebページ内で表示する。

## Copilot
Copilotをメインに使用した開発を学習する。
    - instructions.md, prompt.md, skills.md, agent.md 

# 環境
- 対象のファイル
    - アプリはローカル環境で実行
    - 表示対象の動画・画像ファイル（フォルダ）もローカル環境が対象
- 言語など
    - Python + Flask/FastAPI + React + TypeScript
    - 備考
        単純なスライドショーではなく「複数フレームを持つローカルメディアビューア」に近い。
        なので、素のHTML/JSだけより、画面側はReactで部品化した方がかなり管理しやすい。

# 構成
Python backend
  - ローカルフォルダ読み込み
  - ファイル一覧作成
  - 設定ファイル管理
  - 画像/動画ファイル配信
  - config の新規/コピー/編集/削除

React frontend
  - 複数フレーム表示
  - スライドショー制御
  - 拡大縮小
  - 画像移動
  - フレーム移動
  - ファイルリスト表示
  - 設定画面

・複数フレーム

・現在表示中ファイル

・画像位置

# 機能
- 対象のファイル・フォルダをブラウザにD&Dして、それを読み込み機能を実行させる想定。
- D&Dした後は、設定に従って、Webページ内で、フレームを複数（１つ以上）表示し、そのフレーム内でスライドショーを表示する。
- 設定を保持可能にする。
    - 設定項目
        - 全般設定
            - フレーム個数            
            - デフォルトのスライドショー間隔
            - デフォルトの動画の音量
            - ブラウザ自体orWebページ自体の動画音量（制御可能であれば - 検討中）
        - フレーム設定
            - 表示位置・大きさ
            - スライドショーON/OFF
            - スライドショー間隔
            - 対象のフォルダパス
            - フィルタ
- 画像・動画のデフォルトの表示位置・大きさは上記設定ファイルのものとする。
- 設定ファイルは切り替え可能
    - 画面内で複数の中から設定ファイルを選択→設定ファイルから機能を実行
    - 設定ファイルの新規作成・設定コピー・編集・削除
        - 設定画面は簡素でよい（1つのテキストEditBoxの中にすべて表示-Windowsのテキストエディタと同じようなもの）
- ビューア機能
    - フレーム内に画像・イメージを表示する。
    - 設定ファイルのフォルダ設定のイメージファイルパスをリスト化して保持し、それを順番に表示する。
    - アプリ起動orフォルダ切り替えなどの、フォルダロード時にフォルダ内の画像・動画をすべて読み込んで、イメージを表示する。
- 対象のファイル拡張子は、
    - 画像: jpg, jpeg, png, bmp, webp
    - gif、アニメーションgif
    - 動画: mpg, mpeg, avi, mp4(h264), その他のmp4    
    上記を最低限対応し、その他必要な拡張子もできるだけ対応する。
- 拡大縮小機能
    - フレーム上で拡大縮小操作をすると、イメージ・動画をフレーム内で拡大縮小する。
    - 拡大してもフレームの外にははみださない表にする。
    - 操作：マウスホイール、キーボード プラスキー、マイナスキー（できればCtrl+プラスキーなどにする）
- 画像移動
    - フレーム内で画像の位置を移動可能にする。
    - フレーム内でマウスDown＋Moveをすると、移動する。
    - フレームの外には出さない。
- 位置・大きさリセット
    - キー（Ctrl＋Enter[仮]）で、フレーム内のPos(0,0)、大きさはフレームにあった大きさにリセット表示する。
    - フレーム外にイメージ
- フレームの移動
    - Webページ内でフレームの移動を可能にする。
- ファイルリストの表示　【★検討中】
    - 仮：任意の操作キーでポップアップ（画面orBOX）でファイルリストを表示。ファイルの選択でイメージ表示切替する。
    - フォルダ設定には複数ディレクトリ設定可能、ファイルリストは複数のディレクトリをまたぐ、なので、
        - ファイルリストビュー（ファイルリストのみ）
        - あとは、ディレクトリを含むファイルリストビュー（各フォルダ設定ごと）を複数用意して、切り替え表示可能にする。
- ディレクトリ切り替え
    - 上記ファイルリストではディレクトリも表示され、ディレクトリの選択で、対象のディレクトリ内のイメージを読み込み、ファイルリストと現在の表示ファイルもリセットする。
- ランダム表示
    - 設定ONでファイルリストをランダムに並び替える。
    - ランダムOFFからONに切り替えたときに、ランダム実行する。
    - ランダム実行時現在のファイル表示は変更しない。
    - ランダム切り替え時、ランダムにしたファイルリスト内を検索し、現在のファイルと同じ場所にリスト位置を移動する。
    - 設定でランダムONの場合は、フォルダロード時にランダム実行する。
