# GitHub Copilot Custom Agents / Prompt / Skills メモ

User:
GithubCopilotのCustom Agentsについて教えてください。

# -------
Chat:
GitHub Copilot の「Custom Agents」は、GitHub Copilot に対して  
「この役割・方針・使えるツール・動作ルールで振る舞ってほしい」  
を定義できる仕組みです。

簡単に言うと、

- 「設計専用AI」
- 「セキュリティレビュー専用AI」
- 「WinForms保守専用AI」
- 「Pythonテストコード生成専用AI」

のような “専門人格” を作れる機能です。

（中略）

- prompt.md → 単発
- skills → 能力部品
- agent → 専門職AI

# -------

- 「明示指定が必要か」

がそれぞれ違います。

（中略）

Agent = 性格  
Instructions = 組織ルール  
Skills = 能力  
Prompt = 今回の仕事
