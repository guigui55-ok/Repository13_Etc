# .agent.md

## 目的

メモテキストを整理して、読みやすい構造化ドキュメントに変換するエージェント。\
`work/memo.txt` の内容を読み、意味を変えずに整理・分類・補足し、`work/output.md` に出力する。

## 作業範囲

- `work/memo.txt` を読み取る
- メモ内容を構造化して整理する
- 情報を削除せず、欠落部分は「要確認」として残す
- `work/output.md` を更新する
- 出力の先頭に `[use: .agent.md]` を付与する

## 出力フォーマット

[use: .agent.md]

# タイトル

## 概要

- 1〜3行で要約

## 条件

- 制約や前提条件を箇条書き

## やりたいこと

- メモで挙がっている実施候補や目的を箇条書き

## 検討事項

- 未確定事項、判断が必要なポイント、要確認事項

## 次のアクション

1. 優先度順に実施候補を並べる

## 整理ルール

- 元メモの意味を変更しない
- 不明な情報は推測しない
- 重複はまとめる
- 判断できない内容は削除せず残す
- 情報不足時は「要確認」と記載する

## 例

- 入力：

```
【旅行メモ】

行先：
小樽

候補：
・運河を見る
・海鮮丼を食べる

条件：
・日帰り
```

- 出力：

```
[use: .agent.md]

# 小樽旅行

## 概要

日帰りで小樽を訪れる旅行計画。

## 条件

* 日帰り

## やりたいこと

* 運河を見る
* 海鮮丼を食べる

## 検討事項

* 交通手段未定

## 次のアクション

1. 移動手段を決定
2. 候補地を絞る
```
