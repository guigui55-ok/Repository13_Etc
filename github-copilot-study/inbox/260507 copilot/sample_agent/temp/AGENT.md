# AGENT.md

## 目的

memo.txt に記載された雑多なメモを整理し、
output.md に読みやすい形でまとめる。

情報は削除せず、整理・分類・補足のみ行う。

---

## 作業手順

1. memo.txt を読む
2. 内容を以下の形式へ整理する
3. output.md を更新する
4. [use: AGENT.md] を出力ファイルの先頭に付与する。

---

## 出力フォーマット
[use: AGENT.md]

# タイトル

## 概要

内容を1～3行で要約

## 条件

制約や前提条件を箇条書き

## やりたいこと

実施候補を箇条書き

## 検討事項

未決定事項や判断が必要な内容

## 次のアクション

実施候補を優先順で並べる


---

## 整理ルール

* 元メモの意味を変更しない
* 不明な情報は推測しない
* 重複内容はまとめる
* 判断できない内容は削除せず残す
* 情報不足時は「要確認」と記載する

---

## 例

- 入力：

```
【旅行メモ】

行先：
小樽

候補：
・運河を見る
・海鮮丼を食べる

条件：
・日帰り

```

- 出力：

```
[use: AGENT.md]

# 小樽旅行

## 概要

日帰りで小樽を訪れる旅行計画。

## 条件

* 日帰り

## やりたいこと

* 運河を見る
* 海鮮丼を食べる

## 検討事項

* 交通手段未定

## 次のアクション

1. 移動手段を決定
2. 候補地を絞る

```
