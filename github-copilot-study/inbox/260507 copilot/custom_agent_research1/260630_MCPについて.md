## MCPが向いている用途

MCPは特に、**複数人・複数プロジェクトで共通利用する外部ツール化**に向いています。

例：

```text

```

つまり、社内で

```text

全員に同じツールを使わせたい
権限管理や監査もしたい
```

という場合にMCPが有効です。
