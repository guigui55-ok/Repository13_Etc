## おすすめ

この一覧をそのまま Markdown にするのではなく、さらに以下の列を追加した**完全版リファレンス**にすると実用性が大きく向上します。

| カテゴリ    | ツール           | 説明            | 危険度 | Agentでよく使う | 備考                |
| ------- | ------------- | ------------- | --- | ---------- | ----------------- |
| read    | readFile      | ファイルを読む       | 🟢  | ★★★★★      | 最も使用頻度が高い         |
| edit    | editFiles     | ファイル編集        | 🟡  | ★★★★★      | 実装Agent必須         |
| execute | runInTerminal | コマンド実行        | 🟠  | ★★★★☆      | シェル操作             |
| browser | clickElement  | ブラウザ操作        | 🟠  | ★★★☆☆      | Playwright利用      |
| vscode  | runCommand    | VS Codeコマンド実行 | 🟠  | ★★★☆☆      | Command Palette実行 |
| search  | codebase      | セマンティック検索     | 🟢  | ★★★★★      | 調査Agentで非常に便利     |

このような形式にすると、「どのAgentにどのツールを許可すべきか」を設計する際の資料として非常に使いやすくなります。
