### あなたが調査しようとしている内容との関係

これは以前から取り組まれている **GitHub CopilotのカスタムAgentやMCPの研究**にもつながります。

現在のカスタムAgentで指定する `tools:` は、**Copilotが認識しているツールの中から「このAgentにはどれを使わせるか」を制御するためのもの**です。

つまり、

* 新しい拡張機能を入れる → 利用可能なツールが増える
* 独自MCPサーバーを追加する → 独自ツールが増える
* Agentの `tools:` を設定する → そのAgentが使えるツールを制限できる

という3層構造になっています。

この仕組みを理解しておくと、「どのAgentにどのツールを許可するか」を設計しやすくなります。
