関連スキル: `agent-customization`
テンプレートと設計原則について、**skills.md** を読み込み、それに従ってください。

ユーザーが `SKILL.md` を作成できるように案内してください。

## 会話から抽出する

まず、会話履歴を確認してください。
もしユーザーが複数ステップのワークフローや手法（例：デバッグ手順、レビュー用チェックリスト、実装パターン）に従っている場合は、それを再利用可能なスキルとして一般化します。

以下を抽出してください：

- 実施している手順（ステップバイステップの流れ）
- 判断ポイントや条件分岐のロジック
- 品質基準や完了判定条件

## 必要に応じて確認する

会話から明確なワークフローが見つからない場合は、以下を確認してください：

- このスキルは最終的に何を生成するべきですか？
- ワークスペース単位のスキルですか？それとも個人用ですか？
- 簡易チェックリストですか？それとも複数ステップの詳細ワークフローですか？

## 反復（Iterate）

1. スキルのドラフトを作成して保存する。
2. あいまいな部分や弱い部分を特定し、その点について質問する。
3. 完成したら、以下をまとめる：
   - このスキルが何を生成するか
   - 試すためのプロンプト例
   - 次に作成すると便利そうな関連カスタマイズ案

高品質なスキルを作成するため、`agent-customization` のガイドラインに従ってください。
