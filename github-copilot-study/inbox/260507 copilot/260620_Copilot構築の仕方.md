

* Copilot主要機能と役割
Instructions：常時適用される前提・ルール

Instructions：常時前提
Agent：目的＋判断方針＋出力
Skill：再利用手順
Prompt：今回依頼

↓
| 要素           | 主に持つもの  | 例           |
| ------------ | ------- | ----------- |
| Instructions | 常識・背景   | フォルダ構成、命名規約 |
| Agent        | 何を達成するか | 調査する、実装する   |
| Skill        | どう進めるか  | 調査→影響→テスト   |
| Prompt       | 今回何をやるか | このフォルダ調査    |


* 構築の仕方
まず手動で質問をしていく。
これを繰り返していく中で、
    まったく同じ質問・依頼があったらprompt化
    質問時に、同じような箇所などが出てきたらAgent化
    同じような手順が出てきたらskill化

↓
① 手動で質問する
↓
② 同じ依頼文 → Prompt化
↓
③ 同じ背景・判断基準 → Agent化
↓
④ 同じ手順 → Skill化
↓
⑤ 毎回必要なら Instructions昇格
