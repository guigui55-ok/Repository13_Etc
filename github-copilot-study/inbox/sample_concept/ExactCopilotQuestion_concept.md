# 目的
Github Copilot の過去の質問を収集する。

# 背景
GitHub Copilot の作業効率化のために、AgentやSkillを作成するが、そのために過去に手動で質問した内容を参考にする必要がある。  
その手動質問の内容を整理・分析するための、Copilot質問収集プログラムを作成する。

# 対象
- OS: Windows11
- 言語: C# .Net Framework 4.8
- プロジェクト種: コンソール
- 実行環境: Windows11
- 利用者: 開発者個人

## 補足
開発者個人が利用する。このため開発者が使用する環境に合わせる。
開発効率を優先するため、コンソールアプリとする。
言語選定について、開発者が現在業務で使用している言語であるC#を選定する。

# 仕様
- GitHub Copilot の質問内容を収集する。
- 質問内容は、質問のタイトル、質問の本文、質問のタグ、質問の作成日時、質問の回答数などを収集する。
- 収集した質問内容は、CSV形式で保存する。
- 特定フォルダを指定して、フォルダ内の全ての質問内容を収集する。
- フォルダを指定しない場合はC:\をルートとして、全てのフォルダを対象にする。
- プログラムの第１引数に、フォルダパスを指定する。（絶対パス）
- Usersフォルダ内の質問内容も収集する。
- 出力ファイルエンコードはUTF-8とする。
- 出力ファイル名は、プログラム実行日時を付与する。(例: CopilotQuestions_20230601_120000.csv)
- エラーが発生した場合は、プログラムを中断する。
- Logについて
	- エラーが発生した場合は、エラーメッセージをログに出力する。
	- 処理の進行状況をログに出力する。
	- プログラム実行の要所で、ログに出力する。（実行開始、関数名、処理内容、処理結果など）
	- 出力ファイル名を最後に出力する。
	- ログは、Usersドキュメントの本プログラム用のログフォルダに出力する。(例: C:\Users\ユーザー名\Documents\CopilotQuestions_Logs)
- ログ出力は、コンソールとログファイルの両方に出力する。
- ログファイル名は、プログラム実行日時を付与する。(例: CopilotQuestions_20230601_120000.log)
