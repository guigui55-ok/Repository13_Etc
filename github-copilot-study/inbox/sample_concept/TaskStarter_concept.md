# コンセプト
本ファイルは、TaskStarterのコンセプトを説明するドキュメントです。

# 目的
複数のアプリを起動するためのツール。
設定ファイル（ini形式）を用いて、起動するアプリのパスとウィンドウサイズ・位置と引数を指定できる。

## 備考
- 現状の目的は、複数の動画プレイヤーを起動することを想定している。

# 詳細
- 起動するアプリのパスは、絶対パスまたは相対パスで指定できる。
- ウィンドウサイズ・位置は、起動するアプリのウィンドウがどのように表示されるかを指定するためのオプションである。
- 本ファイルは1つの設定ファイルをセットして、複数のアプリを起動する。
- 設定ファイルには、複数のセクションを定義できる。各セクションは、起動するアプリの設定を表す。
- 設定ファイルは、他のアプリの設定も含むが、関連しない項目は読み取りをスキップする。
- 閉じるボタンで、アプリを終了する。
	- 設定ファイルのCloseFileName項目に、終了するアプリのファイル名を指定する。

## 画面
- TaskStarterは1画面で構成する。
- 画面には、設定ファイルの内容を設定するテキストエリアと、
  実行ボタンと、関連するツールを実行するためのボタンを配置する。

### 実行ボタン
- 実行ボタンを押すと、設定ファイルの内容を読み取り、起動するアプリのパスとウィンドウサイズ・位置と引数を指定して、アプリを起動する。

### 関連するツールを実行するためのボタン
- 本アプリに関連するツールを起動する。
- 起動するアプリは、設定ファイルに記載されたbatファイルを起動する。
- batファイルは、TaskStarter.exeと同じフォルダに配置する。


## 設定ファイル例
[Task1]
FilePath=C:\ZMyFolder\document\TaskStarter
FileName=Laa2.xspf
Parameter=""
Position=50,0
WindowRect=680,520
Random=1
IncludeFileName="ss","s","-aa"

[Task2]
FilePath=C:\ZMyFolder\document\TaskStarter
FileName=Laa2.xspf
Parameter=""
Position=50,520
WindowRect=680,520
Random=1

### 設定ファイル備考
- 本アプリに関連するのは、FilePath, FileName, Parameter, Position, WindowRect の項目である。

### 設定項目
- FilePath: 起動するアプリのパス
- FileName: 起動するアプリのファイル名
- Parameter: 起動するアプリの引数
- Position: 起動するアプリのウィンドウの位置（左上の座標）
- WindowRect: 起動するアプリのウィンドウのサイズ（幅, 高さ）
- その他は、関連しない項目である。（別アプリで使用する項目）

	- テキストボックスにフォーカスがあるとき、上キー、下キーで、設定ファイルを切り替える。
	- 上記の切り替えは、同じフォルダを名前でソートした順番を順次切り替える。
		- アプリ起動時に、設定ファイルをセットして、フォルダ内の設定ファイルを取得し、現在の位置を記憶しておく。
