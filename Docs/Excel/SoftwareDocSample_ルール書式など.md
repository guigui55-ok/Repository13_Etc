■エクセル資料作成時のルールなどメモ
    行の高さ・列幅を同一値に設定（例：20×20）
    ※セル結合しない
        日付は自動で幅調整されるので注意
        （別の文字列と一緒にする。作成日：26//01/11）
    文字サイズ：11pt
    セル右端：A ～ W（23列前後）まで（最大でも X 列まで）
    書類化（紙印刷、PDF）を想定
    エクセル表示の倍率は 85%～100％
    フォント：Yu Gothic UI
    　　社外提出・長期保存（印刷安定・環境差が最小）→游ゴシック
    フォントサイズ	11pt
    列幅	2.38
    行高さ	18.0
    　（初期値：列の幅=8.38、行の高さ=18.7）
    余白（おすすめ）
        上：15mm、下：15mm、左：12mm、右：12mm
        ヘッダー：8mm、フッター：8mm
    印刷範囲を設定（例：A1:V200 など）

■タイトル・ヘッダ・フッタの型（設計書っぽく仕上がる）
ヘッダー（上段）
    左：システム名（例：テストアプリ1）
    中央：資料名（詳細設計書_ファイル暗号化）
    右：版数（v0.1）

ヘッダー（2段目）
    左：作成日（2026/01/10）
    中央：作成者（OK）
    右：ページ番号（Page &P / &N）
