あるアプリ（C#.net デスクトップ）について、あまり機能を変更せずほぼ同じソースで別Editionを作成します。
また、既存Editionと別Editionを同じPCで動作させます。
このアプリは、クライアント・サーバーで連携しているシステムです。
サーバー環境は、Asp.net（asmx）とDB（Sql Server）です。

既存クライアントと別Editionサーバー、別Editionクライアントと既存サーバーはアクセス不可にしたいです。（※１）


※１のアクセス制限の実装を追加します。
このアクセス制限の実装方法について、
既存クライアントとサーバーはリリース済みなので変更不可のため、別Editionクライアントとサーバーのみで対応しなければなりません。

さて、ここで、既存クライアントアプリからサーバーへのアクセス（ログイン処理）は、DBのテーブルの一覧を取得した後、Sql Serverのストアドで、ユーザー情報を照合しています。
（**ここの処理では、asmxのWebメソッドは使用していません。ですのでWebメソッドは今回使用しない前提とします**）

既存クライアントから別Editionのアクセス禁止を、以下のように実装したいのですが、可能でしょうか？

* DBのストアドに引数を追加し、別Editionであることを示す識別子を渡す。
* DBのストアド内に定数を設置（別Editionの識別しをセット）
* DBのストアドで、その引数の識別子と、ストアド内の定数を比較し、一致したら、別Edition==trueとして、認証OKとする。
引数に識別子が無ければ、認証NGとする。
* ストアドの戻り値にも、別Edition識別子を追加して戻すようにする。
* 別Editionクライアントでは、その識別子を取得して、からでなければ、別Editionサーバーかを判定する。
