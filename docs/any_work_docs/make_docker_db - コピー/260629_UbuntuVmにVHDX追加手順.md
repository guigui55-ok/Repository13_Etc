画像がこちらには表示されていないようです（「添付画像」とありますが、こちらでは受信できていません）。

ただ、**手順2（`mklabel gpt`）まで完了している**のであれば、次はパーティションの作成です。

`parted` のプロンプト (`(parted)`) が表示されている状態で、以下を実行してください。

```text
mkpart primary ext4 1MiB 100%
```

> ※ `0%` からでも作成できますが、`1MiB` 開始にしておくとアライメントが適切になり、実務でもよく使われる指定です。

続いて、作成されたことを確認します。

```text
print
```

期待する出力は、おおよそ次のようになります。

```text
Number  Start   End     Size    File system  Name     Flags
 1      1049kB  127GB   127GB                primary
```

確認できたら

```text
quit
```

で `parted` を終了してください。

その後は以下のコマンドです。

```bash
sudo mkfs.ext4 /dev/sdb1
```
