# 構築手順書（Build Manual）

案件名:
学習用サーバー環境構築および設計書整備

版数:
v0.1

目的:
詳細設計書を基に、環境を再現可能な手順として定義する。

---

# 1. 作業概要

対象:
VM4（Ubuntu Desktop LTS）

作業内容:

* VM作成
* OS導入
* Docker導入
* SQL Server導入
* 接続確認

想定時間:
4～8時間

---

# 2. 事前準備

確認事項:

* Hyper-V利用可能
* HDD空き容量確認
* インターネット接続可能
* SSMS利用可能
* Ubuntu ISO取得済み

成果物:

* Ubuntu ISO
* 作業ログ

---

# 3. VM作成

目的:
VM4作成

手順:

1. Hyper-V起動
2. 新規VM作成
3. 以下設定

| 項目   | 設定      |
| ---- | ------- |
| 名前   | VM4     |
| 世代   | 第2世代    |
| メモリ  | 8192MB  |
| CPU  | 4       |
| ディスク | 100GB以上 |

完了条件:

* VM作成成功
* 起動確認

---

| タイムゾーン | Asia/Tokyo |
