では、**MobaXtermからUbuntuへSSH接続する手順**を説明します。

今回は、

* Windows VM（WinDev）から
* Ubuntu Server（VM3）
* Internalネットワーク（172.16.10.20）

へ接続する前提です。

---

# ① MobaXtermを起動

起動後、

**Session** をクリックします。

```
Session
```

---

# ② SSHを選択

```
SSH
```

をクリックします。

---

# ③ 接続情報を入力

以下のように設定します。

| 項目               | 設定値                        |
| ---------------- | -------------------------- |
| Remote host      | `172.16.10.20`             |
| Specify username | ☑ チェック                     |
| Username         | Ubuntu作成時のユーザー名（例：`toshi`） |
| Port             | 22（デフォルト）                  |

例えば、

```
Remote host
172.16.10.20

Port
22

Username
toshi
```

---

# ④ OK

OKを押します。

---

# ⑤ 初回接続

初回は

```
The server's host key is not cached...
```

のような画面が出ます。

これは

> 「このサーバーを信頼しますか？」

という意味なので、

**Accept**（または Yes）を選択します。

---

# ⑥ パスワード入力

Ubuntuインストール時に設定した

```
Password
```

を入力します。

※入力中は文字が表示されませんが正常です。

Enterを押します。

---

# ⑦ 接続成功

成功すると、

```
toshi@Ubuntu:~$
```

のようなプロンプトが表示されます。

これでSSH接続完了です。

---

# もし接続できない場合

まずはWindows VMから

```cmd
ping 172.16.10.20
```

を実行してください。

通れば次に

```cmd
telnet 172.16.10.20 22
```

（または PowerShell の `Test-NetConnection 172.16.10.20 -Port 22`）

でSSHポートを確認します。

Ubuntu側では

```bash
sudo systemctl status ssh
```

でSSHサービスが起動していることを確認してください。

---

## 実務での運用

実務では、このあと**公開鍵認証**へ移行することがほとんどです。

最初はパスワード認証で接続確認を行い、その後

* SSH鍵を作成
* 公開鍵をUbuntuへ登録
* パスワード認証を無効化

という流れになります。

今回も、SSH接続が確認できたら、次のステップとして**公開鍵認証**に切り替えてみることをおすすめします。これは実務でも非常によく使われる構成です。
