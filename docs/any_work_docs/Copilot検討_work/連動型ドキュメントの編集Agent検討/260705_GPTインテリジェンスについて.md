## Toshiさん向けの実運用

私は次のようにします。

```text
普段の開発相談
GPT-5.5 + 標準
```

```text
簡単なコマンド確認・短いコード修正
GPT-5.5 + 最速
```

```text
変更影響調査
複数ドキュメントの整合性レビュー
複雑な設計判断
難しい不具合分析

GPT-5.5 + 高
```

つまり、**モデル変更より先にインテリジェンス設定を変更する**という考え方です。

### モデル切り替えが有効なのは比較研究のとき

今回Toshiさんは、

> CopilotとChatGPTで同じ作業をさせて違いを理解したい

という目的も持っています。

その延長で、

```text
同じ変更影響調査を
GPT-5.5
GPT-5.4
o3
```

に実施させて比較するのは、学習としてかなり面白いと思います。

ただし、通常の開発作業で毎回、

> この質問は5.4かな？
> これはo3かな？

と考える必要はないです。

**私のおすすめは「GPT-5.5固定を基本、推論量だけ切り替える」です。**

たとえば今回のProjectでは、

```text
通常：
GPT-5.5 / 標準

簡単な質問：
GPT-5.5 / 最速

重要な設計・影響調査：
GPT-5.5 / 高

AI比較実験：
GPT-5.4・GPT-5.3・o3も試す
```

という運用が一番シンプルです。
