今回VMなので「仮想リソース（CPU/RAM/Disk）」だけ決めていますが、物理サーバーに置き換わると **機器調達（見積）工程が追加** されます。

# 実務では何を見積もるか

今回のVM4条件を置き換えるとこんな感じです。 

| カテゴリ   | 見積対象        | 例                         |
| ------ | ----------- | ------------------------- |
| サーバー本体 | CPU・RAM・SSD | MiniPC、ラックサーバー            |
| OS     | ライセンス       | Ubuntu無料、Windows Server有償 |
| ストレージ  | 追加SSD、RAID  | 1TB×2                     |
| ネットワーク | スイッチ、LAN    | 管理用NW                     |
| バックアップ | NAS、外付けSSD  | 世代管理                      |
| 電源     | UPS         | 停電対策                      |
| 保守     | 故障交換        | オンサイト保守                   |
| 運用     | 監視、更新作業     | 月次                        |
| 設置     | ラック、スペース    | 社内DC                      |

# 今回の学習サーバーを物理化するとどうなるか

前提：

* Ubuntu Desktop LTS
* Docker
* SQL Server / 今後DB追加
* GUI操作あり 

## 構成案A（学習用・個人）

一番現実的。

| 項目  | 案                        |
| --- | ------------------------ |
| CPU | 8コア程度（Core i5 / Ryzen 5） |
| RAM | 32GB                     |
| SSD | 1TB NVMe                 |
| NIC | 1GbE                     |
| UPS | なし                       |
| 概算  | 10～15万円                  |

用途：

* Ubuntu
* Docker
* SQL Server
* Oracle試験
* VM複数

---

## 構成案B（実務練習寄り）

将来のサーバー案件意識。

| 項目  | 案           |
| --- | ----------- |
| CPU | 12～16コア     |
| RAM | 64GB        |
| SSD | 1TB×2 RAID1 |
| NIC | 2ポート        |
| UPS | 小型UPS       |
| 概算  | 20～35万円     |

用途：

* VM複数
* DB複数同時起動
* 障害試験
* バックアップ
