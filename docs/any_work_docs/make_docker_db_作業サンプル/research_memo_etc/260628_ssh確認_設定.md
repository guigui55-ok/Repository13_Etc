
実務でも、**OSインストール直後にSSH接続を確認し、その後の作業はSSHで行う**ことが多いです。

## 手順

### ① UbuntuのIPアドレスを確認

Ubuntuで

```bash
ip addr
```

または

```bash
hostname -I
```

を実行します。

例えば

```text
172.17.135.16
```

のようなIPが表示されます。

---

### ② SSHサービスが起動しているか確認

```bash
sudo systemctl status ssh
```

または

```bash
sudo systemctl status sshd
```

結果が

```text
active (running)
```

ならOKです。

もし起動していなければ

```bash
sudo systemctl enable --now ssh
```

で起動します。

---

### ③ Windowsから疎通確認

PowerShellで

```powershell
ping <UbuntuのIP>
```

例

```powershell
ping 172.17.135.16
```

※ Hyper-VのDefault Switchでは、Pingが通らないこともあります。通らなくてもSSHは接続できる場合があります。

---

### ④ MobaXtermで接続

新しいSessionを作成します。

```
Protocol : SSH
Remote host : 172.17.135.16
Port : 22
Username : toshi（作成したユーザー）
```

接続するとパスワードを聞かれるので、Ubuntuで設定したパスワードを入力します。

---

## 接続できない場合の確認

順番に確認します。

1. SSHサービス起動

```bash
sudo systemctl status ssh
```

2. ポート22待ち受け

```bash
ss -tln
```

ここに

```text
:22
```

があればOKです。

3. IPアドレス

```bash
hostname -I
```

---

## 実務で気になる点

一点だけ気になっています。

現在は**Hyper-VのDefault Switch**ですよね。

このネットワークだと、

* IPアドレスが変わることがある
* NAT配下になる

ため、学習初期は問題ありませんが、将来的に

* Windows ⇔ Ubuntu
* 複数VM同士
* SQL Server接続

などを安定して行うなら、**「外部仮想スイッチ（External Switch）」または「内部仮想スイッチ（Internal Switch）」**への変更も検討すると、より実務に近い環境になります。

---

### まずはこの順番で進めましょう

1. `hostname -I` でIP確認
2. `sudo systemctl status ssh`
3. MobaXtermから接続

接続できたら、その後のOS初期設定やDocker・SQL Serverの構築は、すべてMobaXterm経由で進めるのがおすすめです。実務でもそのような運用が一般的です。
