## 1. 概要

Linux（Ubuntu LTS）を利用した学習用サーバー環境を構築する。

本作業では、単なる環境作成ではなく、
設計・構築・テスト・運用設計まで含めた、
実務を想定したドキュメント整備も対象とする。

* VM構築
