# 1. 目的
※concept.mdの目的とほぼ一緒

Linuxサーバー構築およびDB構築について、
実務的な進め方を学習するための環境を構築する。

また、設計・構築・テスト・運用までの成果物を整備し、
今後の実務案件対応時の参考資料とする。

# 2. 背景
※concept.mdの背景・詳細とほぼ一緒

作成者はアプリケーション開発経験はあるが、
サーバーおよびDB構築経験は限定的である。

そのため、単なる動作環境作成ではなく、
実務で行われる工程・成果物を意識して実施する。

作成するDBの使用目的は、作成者が本業で使用する事前調査や学習のためである。

# 3. 対象範囲
※具体的な作業を思い浮かべながら、その要所を記載する。
[重要]必ずやらないことを記載する。

対象:

* Hyper-V上のVM構築
* VM内の環境構築
    * Ubuntu Desktop LTS導入
    * Docker導入
    * SQL Server導入
* クライアントからの接続確認
* 品質確認
    * テスト実施
* 運用設計
* ドキュメント整備

対象外:

* Oracle構築
* PostgreSQL構築
* 冗長化構成
* クラウド移行
* 本番運用
* 自動監視
* バックアップ自動化

# 5. 機能要件
※対象範囲を深堀り
利用シーン・シナリオを想定して、各要素ごとに一覧・分類化したもの。

## 必須

* VMを起動できる
* Ubuntuへログインできる
* Dockerが利用できる
* SQL Serverへ接続できる
* SSMSからDB操作できる
* 手順書から再構築できる

## 任意

* Docker Compose利用
* DB追加導入
* CLIのみ構築手順作成

---

# 6. 非機能要件
※利用シナリオで障害となりうるケースをそれぞれ想定し、その対応を検討。

## 性能

* VM4は8GB／4CPUを初期値とする
* 通常操作時に著しい遅延が発生しないこと

## 可用性

* スナップショット取得可能

## 保守性

* 再構築手順を残す

## 学習性

* GUI操作可能
