# テスト設計書（Test Design）

案件名:
学習用サーバー環境構築および設計書整備

版数:
v0.1

目的:
要件定義書および設計書を基に、
テスト対象・観点・方針を定義する。

詳細な手順はテスト仕様書で定義する。

---

# 1. テスト方針

本テストでは、
環境構築完了後に、
利用可能状態であることを確認する。

正常系確認を優先し、
異常系は必要最小限とする。

---

# 2. テスト対象

対象:

* Hyper-V
* VM4
* Ubuntu
* Docker
* SQL Server
* SSMS接続
* 構築手順
* ドキュメント

対象外:

* 本番運用
* 長時間負荷試験
* 可用性試験
* 性能試験（高負荷）
* セキュリティ診断

---

# 3. テストレベル

| レベル  | 対象          |
| ---- | ----------- |
| 単体   | 個別導入確認      |
| 結合   | Docker・DB連携 |
| システム | 全体利用確認      |
| 受入   | 受入条件確認      |

---

# 4. テスト観点

## 機能

確認内容:

* VM起動
* Ubuntuログイン
* Docker利用
* SQL Server利用
* SSMS接続

---

## 非機能

確認内容:

* 起動可能
* 再構築可能
* セキュリティ設定確認
* 手順整備確認

---

## 運用

確認内容:

* 起動停止
* 再構築
* 手順確認

---

# 5. テスト観点マトリクス

| 要件         | 確認観点  |
| ---------- | ----- |
| VM利用可能     | 起動    |
| Docker利用可能 | 導入・起動 |
| SQL利用可能    | 接続    |
| 再構築可能      | 手順    |
| 運用可能       | 手順確認  |

---

# 6. テスト方式

| 方式     | 利用  |
| ------ | --- |
| 目視     | ○   |
| CLI確認  | ○   |
| SSMS確認 | ○   |
| ログ確認   | △   |
| 自動化    | 対象外 |

---

# 7. 合否判定

合格:

* 重大不具合なし
* 全観点確認済

不合格:

* 接続不可
* 再現不能
* 手順不備

---

# 8. 成果物

出力:

* テスト仕様書
* テスト結果
* 課題一覧
