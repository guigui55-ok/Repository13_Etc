Ubuntu Serverでは **Netplan** で設定します。今回は `eth1` に Internal 用IPを固定設定します。

## 1. 設定ファイル確認

```bash
ls /etc/netplan/
```

例：`50-cloud-init.yaml` や `00-installer-config.yaml` が表示されます。

## 2. 編集

表示されたファイル名に合わせて編集します。

```bash
sudo nano /etc/netplan/50-cloud-init.yaml
```

ファイル名が違う場合は置き換えてください。

## 3. 設定例

`eth0` は既存のDHCPのまま、`eth1` を追加します。

```yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: true
    eth1:
      dhcp4: false
      addresses:
        - 172.16.10.20/24
```

※ `eth1` には gateway / DNS は書きません。

## 4. 保存

nanoの場合：

```text
Ctrl + O
Enter
Ctrl + X
```

## 5. 適用前チェック

```bash
sudo netplan try
```

問題なければ Enter で確定します。

## 6. 適用

```bash
sudo netplan apply
```

## 7. 確認

```bash
ip addr
```

`eth1` に以下が付いていればOKです。

```text
172.16.10.20/24
```

その後、Windows VMから：

```cmd
ping 172.16.10.20
```

MobaXtermでは `172.16.10.20` にSSH接続してください。
