まずは、**4GB固定・動的メモリOFFで安定した**とのこと、おめでとうございます！
実務でも「まず安定稼働を確認してから構築を進める」のはとても大切な手順です。

## OS初期設定とは？

一言で言うと、

> **「ミドルウェア（DockerやSQL Server）を入れる前に、OSを運用できる状態に整える作業」**

です。

今回の学習目的なら、私は次の順番をおすすめします。

| 優先 | 作業            | 目的                  |
| -: | ------------- | ------------------- |
|  ① | OS情報確認        | 環境を把握する             |
|  ② | パッケージ更新       | 最新状態にする             |
|  ③ | タイムゾーン確認      | 時刻を正しくする            |
|  ④ | ホスト名確認        | 設計通りか確認する           |
|  ⑤ | SSH接続確認       | Windowsから管理できるようにする |
|  ⑥ | ファイアウォール(UFW) | 最低限のセキュリティ          |
|  ⑦ | 必要ツール導入       | `curl`、`git`など      |

---

## 具体的には

### ① OS情報確認

```bash
cat /etc/os-release
uname -a
hostnamectl
free -h
df -h
```

---

### ② パッケージ更新

```bash
sudo apt update
sudo apt upgrade
```

---

### ③ タイムゾーン確認

```bash
timedatectl
```

日本になっていなければ

```bash
sudo timedatectl set-timezone Asia/Tokyo
```

---

### ④ ホスト名

```bash
hostnamectl
```

設計通り

```
linuxdevdb
```

などになっているか確認します。

---

### ⑤ SSH接続

Windowsから

```powershell
ssh toshi@192.168.xxx.xxx
```

で接続できるか確認します。

これができると、Hyper-Vコンソールを開かなくても管理できます。

---

### ⑥ ファイアウォール

まだSQL Serverを入れないので、

```bash
sudo ufw status
```

程度の確認で十分です。

---

### ⑦ 必要ツール

私は最初にこれだけ入れます。

```bash
sudo apt install \
curl \
wget \
git \
vim \
net-tools
```

## 私からの提案

今回の学習では、**ただコマンドを実行するだけでなく、「なぜその設定を行うのか」を理解すること**も目的にすると、実務で応用しやすくなります。

例えば、

* なぜ `apt update` と `apt upgrade` を実行するのか
* なぜ `hostname` を確認するのか
* なぜ SSH 接続を確認するのか

といった「目的」も手順書に1～2行添えておくと、後から見返したときに理解しやすいドキュメントになります。
