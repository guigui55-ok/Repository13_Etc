はい、**どちらもインストールする必要はありません。どちらか一方だけで十分**です。

Ubuntu Serverであれば、通常は **apt** を使うのがおすすめです。

```bash
sudo apt update
sudo apt install -y tree
```

インストールが終わったら、もう一度実行します。

```bash
tree /srv/docker
```

### snap版とapt版の違い

* **apt版**（おすすめ）

  * Ubuntu標準のパッケージ管理
  * 軽量
  * システム管理コマンドに向いている
* **snap版**

  * アプリケーション向け
  * 起動が少し遅いことがある
  * サンドボックス化される

学習用やサーバー用途では、**apt版を使うことがほとんど**です。
