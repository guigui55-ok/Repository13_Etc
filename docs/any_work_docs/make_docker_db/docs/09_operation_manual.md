# 運用手順書（Operation Manual）

案件名:
学習用サーバー環境構築および設計書整備

版数:
v1.0

---

# 1. 目的

本書は、構築した学習用サーバー環境の日常運用に必要な作業手順を定義する。

運用方針については運用設計書に従う。

---

# 2. 運用対象

* Hyper-V
* VM4
* Ubuntu Desktop LTS
* Docker
* SQL Server
* 関連ドキュメント

---

# 3. 起動手順

## VM起動

1. Hyper-Vを起動する。
2. VM4を起動する。
3. Ubuntuが正常に起動することを確認する。

確認項目

* Ubuntuへログインできること
* エラーが発生していないこと

---

## Docker起動確認

1. ターミナルを起動する。
2. Dockerサービス状態を確認する。

確認項目

* Dockerが利用可能であること

---

## SQL Server起動確認

1. SQL Serverサービスを確認する。
2. 必要に応じて起動する。

確認項目

* SQL Serverへ接続可能であること

---

# 4. 停止手順

## SQL Server

1. 作業終了を確認する。
2. SQL Serverを停止する（必要な場合）。

## Docker

1. 利用中コンテナを停止する。
2. 不要なコンテナが残っていないことを確認する。

## VM

1. Ubuntuを正常終了する。
2. Hyper-VからVMを停止する。

---

# 5. 更新手順

## OS更新

1. 更新情報を確認する。
2. 更新前にHyper-Vチェックポイントを取得する。
3. OS更新を実施する。
4. 再起動する。
5. 動作確認を行う。

---

## Docker更新

1. バージョンを確認する。
2. 更新前にチェックポイントを取得する。
3. 更新を実施する。
4. 動作確認を行う。

---

## SQL Server更新

1. 更新情報を確認する。
2. 更新前にチェックポイントを取得する。
3. 更新を実施する。
4. SSMS接続確認を行う。

---

# 6. 障害対応手順

## VM起動不可

1. Hyper-V設定確認
2. チェックポイント復元（必要時）
3. 復旧不可の場合は再構築

---

## Docker異常

1. サービス状態確認
2. ログ確認
3. 必要に応じて再導入

---

## SQL Server異常

1. サービス状態確認
2. 接続設定確認
3. 必要に応じて再導入

---

# 7. チェックポイント取得手順

取得タイミング

* 大規模更新前
* 設定変更前
* ソフトウェア追加前

確認項目

* チェックポイント名
* 取得日時

---

# 8. ドキュメント更新手順

以下の場合は関連資料を更新する。

* 構成変更
* 設定変更
* ソフトウェア追加
* 運用変更

更新対象

* 基本設計書
* 詳細設計書
* 構築手順書
* テスト関連資料
* 運用設計書
* 運用手順書

---

# 9. 定期確認手順

必要に応じて以下を確認する。

* OS更新状況
* Docker更新状況
* SQL Server更新状況
* ディスク空き容量
* 不要ファイル

---

# 10. 運用記録

運用作業を実施した場合は、以下を記録する。

| 項目   | 内容               |
| ---- | ---------------- |
| 実施日時 | YYYY/MM/DD hh:mm |
| 担当者  | 作成者本人            |
| 作業内容 | 実施内容             |
| 結果   | 正常／異常            |
| 備考   | 必要事項             |

---

# 11. 注意事項

* 作業前に重要データの保護状況を確認する。
* 大規模変更前はHyper-Vチェックポイントを取得する。
* 障害発生時は原因を確認し、復旧が困難な場合は構築手順書に従って再構築する。
* 運用ルールを変更した場合は、運用設計書もあわせて更新する。
