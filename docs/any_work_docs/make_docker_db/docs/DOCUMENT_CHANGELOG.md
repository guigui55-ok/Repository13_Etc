## 記録ルール

* 同一の変更目的・実績反映に基づく一連のドキュメント修正は、同一の変更IDを使用する。
* 設計内容、設定方針、構成、手順、テスト観点、運用方針に影響する変更を記録対象とする。
* 表記修正、誤字修正、軽微な文章調整など、内容上の意味を変更しない修正は記録対象外とする。
* 項番変更に備え、変更箇所は項番とカテゴリ名を併記する。
* 今後、要件定義書、詳細設計書、構築手順書、テスト関連資料、運用設計書、運用手順書を同期する際は、本表へ追記する。
