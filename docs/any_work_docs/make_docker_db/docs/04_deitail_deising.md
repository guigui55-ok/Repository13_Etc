# 1. 目的

基本設計書で決定した構成について、
具体的な設定値および構築条件を定義する。

本書を基に構築手順書を作成する。

# 2. VM設定

## VM4

| 項目       | 設定値                |
| -------- | ------------------ |
| 仮想化基盤    | Hyper-V            |
| VM名      | VM4                |
| OS       | Ubuntu Desktop LTS |
| メモリ      | 8192MB             |
| CPU      | 4                  |
| ディスク     | 100GB以上            |
| 起動方式     | 手動                 |
| スナップショット | 必要時取得              |

## 運用制約

* VM4使用時はVM3停止推奨
* 必要に応じてVM2停止

# 4. ネットワーク設定

## 接続方針

| 通信           | 許可 |
| ------------ | -- |
| Windows→VM4  | 許可 |
| VM4→Internet | 許可 |
| 外部→VM4       | 禁止 |

## ポート

| 用途         | ポート     |
| ---------- | ------- |
| SSH        | 22（必要時） |
| SQL Server | 1433    |
| Docker     | 必要時のみ   |

# 7. セキュリティ設定

## OS

* 初期認証情報変更
* 不要サービス停止
* OS更新適用

## Docker

* 不要コンテナ停止
* 不要ポート未公開

## SQL Server

* 強固なパスワード設定
* 不要ユーザー未作成

## ドキュメント

* 認証情報を記載しない

# 8. ディレクトリ設計

```text
/
├ docker/
├ db/
├ project/
├ backup/
└ documents/
```

用途:

* docker: コンテナ関連
* db: DB関連
* project: 学習用作業
* backup: 一時保存
* documents: 手順・設計

---

# 9. ログ設計

| 対象         | 保存 |
| ---------- | -- |
| OS         | 既定 |
| Docker     | 既定 |
| SQL Server | 既定 |

詳細な監視は対象外。

---

# 10. 異常時方針

| 事象       | 対応         |
| -------- | ---------- |
| OS異常     | 再構築        |
| Docker異常 | 再導入        |
| DB異常     | 再作成        |
| 設定誤り     | スナップショット復元 |
