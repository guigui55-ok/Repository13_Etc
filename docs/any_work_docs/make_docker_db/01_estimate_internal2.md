# 見積・計画（Estimate） 内部 - 工数見積もり

## 見積条件

* 見積種別: 概算見積（内部用）
* 前提:

  * 事前調査完了済み
  * 個人学習目的
  * 実務的なドキュメント整備を含む
  * Linux/サーバー構築経験は限定的
* 精度:

  * ±50%（学習・調査要素が大きいため）

---

## 期間

1～2週間

想定作業時間:
18～24h

---

## 工数見積

| 工程       | 内容                |   工数 |
| -------- | ----------------- | ---: |
| 01 見積・計画 | 見積・方針整理           |   2h |
| 02 要件定義  | 目的・制約・完成条件整理      |   2h |
| 03 基本設計  | 構成・OS・DB・VM設計     |   3h |
| 04 詳細設計  | 設定値・手順・運用方針       |   3h |
| 05 構築手順  | 手順書作成             |   2h |
| 06 構築    | VM・OS・Docker・DB構築 | 4～6h |
| 07 テスト   | 接続確認・動作確認         |   2h |
| 08 運用設計  | バックアップ・更新方針       |   1h |
| 09 振り返り  | 課題整理・改善           |   1h |

合計:
20～22h

---

## 見積外

* Oracle構築
* PostgreSQL構築
* Docker本番運用設計
* 高可用性構成
* 監視構築
* セキュリティ強化

---

## リスク

| 内容         | 影響    | 対策          |
| ---------- | ----- | ----------- |
| Linux理解不足  | 構築遅延  | AIアシストで補完（できれば小規模検証）       |
| Docker理解不足 | 再構築発生 | 小規模のため不要（できればPoC実施）       |
| 容量不足       | 環境変更  | Data.vhdx分離 |
| 構築失敗       | 手戻り   | スナップショット    |
| 工数超過       | 期間延長  | 優先順位管理      |

---

## 判断ポイント（Go/NoGo）

以下の条件を満たしたら完了とする。

* Ubuntu起動
* Docker起動
* DB接続成功
* 手順書更新完了
* テスト完了
* 運用メモ作成完了
