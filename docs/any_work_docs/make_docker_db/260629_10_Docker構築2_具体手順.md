# 6. Docker基盤構築

## 6.1 目的

Docker EngineおよびDocker Composeを導入し、コンテナ実行基盤を構築する。

Dockerの永続データはデータ用ディスク(`/srv/docker`)へ配置し、OSとデータを分離する。

# 6.3 Docker公式Repository追加

## 必要パッケージ

```bash
sudo apt install -y \
ca-certificates \
curl \
gnupg
```

---

## GPGキー登録

```bash
sudo install -m 0755 -d /etc/apt/keyrings
```

```bash
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
```

```bash
sudo chmod a+r /etc/apt/keyrings/docker.gpg
```

---

## Repository追加

```bash
echo \
"deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
https://download.docker.com/linux/ubuntu \
$(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

---

## パッケージ更新

```bash
sudo apt update
```

## 実務であれば、ここでチェックポイントを取得します

Docker基盤が完成した時点で、Hyper-Vのチェックポイント（例: **「Docker基盤構築完了」**）を作成しておくことをおすすめします。

その後は、この安定した状態を基点として

1. SQL Server
2. Nginx
3. Redis
4. PostgreSQL

などを個別に追加していけば、問題が起きてもDocker基盤だけはすぐに復元できるため、実務でも管理しやすい運用になります。
