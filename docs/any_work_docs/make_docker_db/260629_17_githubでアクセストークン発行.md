原因は、**GitHubのパスワード認証が使えないため**です。GitHub公式でも、Git操作ではパスワードではなく **Personal Access Token** などを使う必要があると説明されています。([GitHub Docs][1])

## 手順

GitHubでトークンを作成します。

`GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens`

設定例：

```text
Repository access: Only select repositories
対象Repository: ubuntu-docker-learning
Permissions:
  Contents: Read and write
```

トークンを作成したら、再度Ubuntuで実行します。

```bash
git push -u origin main
```

聞かれたら：

```text
Username for 'https://github.com': guigui55-ok
Password for 'https://guigui55-ok@github.com':
```

ここで **Password欄にGitHubパスワードではなく、作成したTokenを貼り付け**ます。

貼り付けても画面には表示されませんが、そのまま Enter でOKです。

うまくいけばPushできます。
