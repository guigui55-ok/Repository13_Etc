# 目的
ソフトウェア開発における、個人学習用のサーバーを構築する。
そのための、設計書的なものも作成する。（実務的なもの）

# 目的の詳細（背景）
この作業について、色々ドキュメントを整備しながら進めたい。
 
筆者（＝本件の作業者）はITエンジニアだが、実務でサーバー、DBを構築が未経験である。 
例えば、今後そのような案件をする場合に、実務でどのような手順を踏むのか、どのようなことが必要なのかを確認しつつ、実務的に必要なドキュメントを作成しながら、作業を進める。

# 環境
OS種: Linux
ディストリビューション: Ubuntu LTS (2026.6.21時点の最新)
設置場所: WindowsVM上のHyper-VのVM内
用途: 開発用PC、各種DB構築用
補足: VM内にDBを直接構築、VM内のDockerに各種プロジェクト個別にVM＋DBを構築

# 必要なDB
* 現在必要なDB
    - SQL Server
    クライアント側からSSMSでアクセスする想定

* 今後構築予定（現在は構築しない）
    - Oracle
    - PostgreSQL
    - MySQL
    - その他実務で有効的に使えそうなものがあれば
