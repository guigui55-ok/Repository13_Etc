# 基本設計書（Basic Design）

案件名:
学習用サーバー環境構築および設計書整備

版数:
v0.1

---

# 1. 目的

本書は、学習用サーバー環境の基本構成および設計方針を定義する。

対象環境は、Hyper-V上に構築するUbuntu Desktop LTSのVMとし、
DockerおよびSQL Serverを利用可能な環境とする。

---

# 2. 前提条件

* ホストPCはWindows11とする
* 仮想化基盤はHyper-Vとする
* ゲストOSはUbuntu Desktop LTSとする
* DBはSQL Serverを採用する
* DB管理クライアントはWindows側のSSMSを利用する
* 学習用途のため、本番運用は対象外とする

---

# 3. 全体構成

```text
ホストPC（Windows11）
  ├ VM1：Windows11（メイン開発用）
  ├ VM2：Linux（サブ開発用）
  ├ VM3：Linux（検証用）
  └ VM4：Ubuntu Desktop LTS（本件対象）
        ├ Docker
        └ SQL Server
```

SSMSはWindows側に配置し、VM4上のSQL Serverへ接続する。

---

# 4. VM設計

## VM4基本設定

| 項目    | 設定                         |
| ----- | -------------------------- |
| 仮想化基盤 | Hyper-V                    |
| OS    | Ubuntu Desktop LTS         |
| メモリ   | 8192MB                     |
| CPU   | 4コア                        |
| ディスク  | 100GB以上                    |
| 用途    | Docker、SQL Server、サーバー構築学習 |

## 設計方針

* GUI操作を可能とするため、Ubuntu Desktopを採用する
* DockerおよびSQL Serverを動作させるため、8GB/4CPUを初期値とする
* ホストPCのリソース制約を考慮し、VM同時起動数を制御する

---

# 5. OS設計

## 採用OS

Ubuntu Desktop LTS

## 採用理由

* GUIとCLIの両方で操作できる
* 学習情報が多い
* DockerおよびSQL Serverの構築情報が多い
* 個人開発環境としても利用しやすい

---

# 6. ネットワーク設計

## 接続方針

* VM4はホストPCおよびクライアント側から接続可能とする
* SQL ServerへSSMSから接続できる構成とする
* 外部公開は行わない

## 公開範囲

| 対象         | 公開方針            |
| ---------- | --------------- |
| Ubuntu操作   | ローカルVM上で実施      |
| SQL Server | ホストPCまたはVM1から接続 |
| Dockerコンテナ | 必要最小限のみ公開       |
| インターネット公開  | 対象外             |

---

# 7. Docker設計

## 利用方針

* Dockerを導入し、今後の開発・DB検証に利用可能な状態とする
* 本フェーズでは複雑なコンテナ運用は対象外とする
* 必要に応じてDocker Composeの利用を検討する

---

# 8. DB設計

## 採用DB

SQL Server

## 管理ツール

SSMS

## 接続方針

* SQL ServerはVM4上に構築する
* SSMSはWindows側にインストールする
* SSMSからVM4上のSQL Serverへ接続確認を行う

---

# 9. セキュリティ設計

## 基本方針

学習用途の閉域環境として構築し、外部公開は行わない。

## セキュリティ方針

* 不要なサービスは起動しない
* 不要なポートは開放しない
* 初期パスワードは変更する
* 認証情報はドキュメントへ平文記載しない
* 管理者権限の常時利用は避ける
* OS・Docker・SQL Serverは構築時点で更新する

---

# 10. 運用設計方針

詳細は運用設計書で定義する。

本基本設計では以下の方針のみ定義する。

* VM起動・停止手順を整理する
* 構築手順書により再構築可能とする
* 障害時はバックアップ復旧ではなく再構築を基本とする
* スナップショット取得を必要に応じて利用する

---

# 11. テスト方針

詳細はテスト仕様書で定義する。

基本設計時点では以下を確認対象とする。

* VM起動確認
* Ubuntuログイン確認
* Docker動作確認
* SQL Server起動確認
* SSMS接続確認
* ドキュメント整備確認

---

# 12. 制約事項

* ホストPCのメモリは32GBである
* VM1、VM2、VM3、VM4の同時起動は避ける
* 本環境は学習用途であり、本番運用・高可用性構成は対象外とする
* Oracle、PostgreSQL等の追加DB構築は本フェーズ対象外とする
