# 要件定義書（Requirements）

案件名:
学習用サーバー環境構築および設計書整備

版数:
v0.1

---

# 1. 目的

実務を意識したサーバー構築手順を学習するため、
Linux環境・DB環境・関連ドキュメントを整備する。

環境構築のみではなく、
設計・構築・テスト・運用設計までの成果物を作成し、
今後の実務案件の参考資料とする。

---

# 2. 背景

作成者はアプリケーション開発経験はあるが、
サーバー・DB構築経験は限定的である。

そのため、構築経験習得と、
成果物作成経験の習得を目的とする。

作成するDBの使用目的は、作成者が本業で使用する事前調査や学習のためである。

---

# 3. 対象範囲

対象:

## 環境構築

* Hyper-V上へのVM構築
* VM内環境構築

  * Ubuntu Desktop LTS導入
  * Docker導入
  * SQL Server導入
* クライアントからの接続確認

## 品質確認

* テスト実施

## ドキュメント整備

* 要件定義
* 基本設計
* 詳細設計
* 構築手順
* テスト仕様
* 運用設計

対象外:

* Oracle構築
* PostgreSQL構築
* 冗長化構成
* 本番運用
* 自動監視
* 自動バックアップ
* セキュリティ監査

---

# 4. システム構成

ホスト:
Windows11

仮想化:
Hyper-V

ゲスト:
Ubuntu Desktop LTS

コンテナ:
Docker

DB:
SQL Server

管理クライアント:
SSMS

---

# 5. 機能要件

* 仮想環境を構築できること
* Ubuntuへログインできること
* Dockerを利用できること
* SQL Serverを利用できること
* SSMSから接続確認できること
* 手順書により再構築可能であること

---

# 6. 非機能要件

## 性能

* VM4は初期値として8GB／4CPUで構築する
* 通常操作時に著しい遅延が発生しないこと

## 可用性

* 障害発生時は再構築による復旧を基本とする

## 保守性

* 構築手順を記録し、再構築可能であること

## 運用性

* 起動・停止・更新手順を整備すること

## セキュリティ

* 外部公開しない閉域学習環境とする
* OS・Docker・SQL Serverは構築時点の安定版を利用する
* 不要サービス・不要コンテナは起動しない
* 初期認証情報は変更する
* 管理者権限での常時運用を避ける
* 認証情報をドキュメントへ平文記載しない

## 制約

* ホストPCの32GBメモリ制約を考慮し、同時起動VM数を制限する

---

# 7. 受入条件

以下を満たした場合、受入可能とする。

* VM起動可能
* Ubuntu利用可能
* Docker利用可能
* SQL Server接続可能
* SSMS接続確認完了
* テスト完了
* ドキュメント更新完了
